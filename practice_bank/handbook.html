ML01 · Stable softmax cross-entropy

Priority: P0 · Base timebox: 35 min

Prompt

NumPy: logits [N,C], integer targets [N]; return mean loss and manual dlogits. No autograd or loss helpers.

Complete practice contract

Inputs are finite float64 logits Z[N,C], C>=2, integer targets y[N]. Return scalar mean negative log-likelihood and dZ[N,C]. Ignore target -100 before indexing. Average over valid rows only; this pack defines an all-ignored or empty batch as zero loss and zero gradient. No input mutation.

Test agenda

Huge logits; per-row shift invariance; zero row-sum gradient; float64 finite differences.

Follow-up challenge

Add ignore_index; define all-ignored behavior; avoid a [C,C] Jacobian.

Worked solution, example and follow-up answer

Solution

For one row, m=max(z), a=z-m, S=sum(exp(a)), p=exp(a)/S. Compute loss as log(S)-a[y], not -log(softmax(z)[y]): the latter can underflow for an extremely unlikely label. Averaging gives dZ=(p-one_hot(y))/N_valid on valid rows. The softmax Jacobian is diag(p)-ppᵀ, but composing it with cross-entropy cancels to p-y; never allocate a per-sample C×C Jacobian.

Correctness follows because subtracting m multiplies numerator and denominator by the same factor. Complexity is O(NC) time and O(NC) output/workspace. Validate labels before fancy indexing; -1 accidentally indexes the last class in NumPy. Use float64 finite differences and both absolute and relative tolerances; compare away from overflow limits.

Worked example

z=[0,0], y=1 gives loss log(2) and gradient [0.5,-0.5]. Two rows [1000,-1000],[-1000,1000] with labels [0,0] give mean loss 1000 and gradients [[0,0],[-0.5,0.5]]. Adding a different constant to each row changes neither result.

Follow-up answer

Ignored targets contribute neither loss nor gradient. A weighted version divides by the sum of valid weights, not N; document zero total weight. Row gradient sums are zero because sum(p)=1. This invariant catches the wrong normalization axis but is not a replacement for finite differences.

ML02 · Linear classifier training loop

Priority: P0 · Base timebox: 30 min

Prompt

Train multiclass W [D,C], b [C] on X [N,D] using ML01; one full-batch update per epoch.

Complete practice contract

X[N,D], W[D,C], b[C], integer y[N], finite nonnegative learning rate. Return new W and b plus the loss computed before the update. Use one parameter snapshot for both gradients.

Test agenda

Gradient shapes; loss decreases on separable toy data; no mutation of X; reproducible seed.

Follow-up challenge

Mini-batches; L2 regularization; weighted examples; data leakage.

Worked solution, example and follow-up answer

Solution

Compute Z=XW+b and obtain dZ from ML01. Chain rule gives dW=XᵀdZ and db=sum_rows(dZ). Then update both parameters simultaneously. The bias reduction keeps C coordinates, not one scalar. Zero initialization is fine for this linear softmax model: class-specific target gradients break the relevant symmetry, unlike hidden units in a multilayer network.

For full-batch training, record pre-update loss each epoch; evaluate once more at final parameters when reporting final performance. Training costs O(NDC) per step. Separate train/validation/test and fit any normalization on training data only. Tiny separable data should overfit; inability to do so usually points to sign, reduction, label, or stale-parameter errors.

Worked example

With X=[[-1],[1]], y=[0,1], W=0, b=0: dW=[[0.5,-0.5]], db=[0,0]. With learning rate 0.1, W becomes [-0.05,0.05], giving the positive input a larger class-1 logit.

Follow-up answer

For objective CE + λ||W||²/2, add λW to dW; do not regularize b unless specified. Unequal microbatches must contribute gradients in proportion to valid-example count. Report whether weights are per example, class, or sampling correction; they are different objectives.

ML03 · Logistic regression

Priority: P1 · Base timebox: 25 min

Prompt

Implement binary logistic regression with stable logits-based loss and analytic gradients.

Complete practice contract

Binary logits z=Xw+b and targets exactly 0/1. Mean logits-based BCE. The reference primitive returns loss and dz; form dw=Xᵀdz, db=sum(dz).

Test agenda

Extreme positive/negative logits; duplicated batch invariant under mean reduction; bias gradient.

Follow-up challenge

Explain MSE versus log-loss and decision thresholds.

Worked solution, example and follow-up answer

Solution

Use softplus(z)-yz = logaddexp(0,z)-yz. The derivative is (sigmoid(z)-y)/N. A stable sigmoid is exp(-logaddexp(0,-z)); a sign-split implementation is also valid. Never write log(1-sigmoid(z)) for large positive z. For a regularized linear model add λw to the gradient.

Logistic regression learns conditional probabilities under its modeling assumptions, not a universally optimal decision threshold. Choose the decision threshold on held-out data for the operational cost and prevalence. The convex BCE objective in linear parameters contrasts with MSE applied after a sigmoid, whose derivative includes an additional p(1-p) factor and can become small for confidently wrong examples.

Worked example

z=0, y=1 produces loss log(2), dz=-0.5 for one example. z=-1000,y=1 produces loss approximately 1000 and dz approximately -1 rather than an infinite loss or zero gradient.

Follow-up answer

With false-positive cost C_FP and false-negative cost C_FN, and calibrated deployment posterior p, predict positive when p>C_FP/(C_FP+C_FN). This assumes those are the only costs. Resampling or class weighting changes the fitted distribution/objective; calibration must be checked again.

ML04 · Linear regression and conditioning

Priority: P1 · Base timebox: 25 min

Prompt

Implement least-squares gradient descent; compare with np.linalg.lstsq without explicitly inverting X.T@X.

Complete practice contract

Minimize ||Xw-y||²/(2N), with an optional unregularized intercept. Support rank-deficient X; do not invert XᵀX. Return a documented iterate or least-squares solution.

Test agenda

Rank deficiency; scale imbalance; intercept handling; analytical toy solution.

Follow-up challenge

Feature scaling; ridge; ill-conditioning and stopping rule.

Worked solution, example and follow-up answer

Solution

Residual r=Xw-y gives gradient Xᵀr/N. Gradient descent updates w←w-ηXᵀr/N. Its Hessian is XᵀX/N; a sufficient constant-step condition for convergence on a quadratic is 0<η<2/λ_max of that Hessian, with the usual flat-direction caveat. Feature scaling improves the spread of eigenvalues and practical convergence.

For a numerical baseline use np.linalg.lstsq, which does not require full column rank. Forming normal equations squares the 2-norm condition number before solving and explicitly taking an inverse adds unnecessary numerical work. Ridge adds λI on regularized coordinates and selects a unique solution when λ>0. State objective normalization: using MSE without the 1/2 doubles the gradient.

Worked example

X=[[1],[2]], y=[2,4]. The optimum is w=2. At w=0 the gradient is (-2-8)/2=-5. A step of 0.1 gives w=0.5. Duplicating both observations leaves the mean gradient unchanged.

Follow-up answer

With collinear columns, predictions may be identified while coefficients are not. Compare training objective and predictions rather than demanding one coefficient vector from every solver. Stop based on gradient/objective/step change plus an iteration budget, not an arbitrary fixed epoch count alone.

ML05 · Two-layer neural network

Priority: P1 · Base timebox: 45 min

Prompt

Implement affine-ReLU-affine classifier forward/backward in NumPy with cached activations.

Complete practice contract

X[N,D] → hidden width H → C logits. Affine-ReLU-affine, mean CE, all parameter gradients returned. Define ReLU derivative at zero as zero; finite differences avoid kinks.

Test agenda

Finite differences away from ReLU zero; tiny-batch overfit; each parameter gets a gradient.

Follow-up challenge

Initialization; activation saturation; parameter count.

Worked solution, example and follow-up answer

Solution

Cache A=XW1+b1 and H=max(A,0). Set Z=HW2+b2 and compute G=dL/dZ. Backpropagate dW2=HᵀG, db2=sum_rows(G), dA=(GW2ᵀ)·1[A>0], dW1=XᵀdA, db1=sum_rows(dA). Do not update W2 before computing dA. Time is O(NDH+NHC); cached hidden activations require O(NH) memory.

Use independently initialized hidden weights; identical hidden units receiving identical updates remain redundant. Check every parameter block separately with finite differences. An overfit test on a handful of examples is stronger than checking only output shape. When a gradient is zero, determine whether it is mathematically zero, masked by ReLU, or accidentally disconnected.

Worked example

For D=2,H=4,C=3, parameter count including biases is 2·4+4+4·3+3=27. A batch N=5 produces A[5,4], G[5,3], dW1[2,4], dW2[4,3].

Follow-up answer

He-style variance scaling addresses ReLU activation scale, not all training instability. Biases that make every preactivation negative can create dead units. Saturating sigmoid/tanh hidden activations create a different vanishing-gradient mechanism. Explain the observed mechanism before changing the optimizer.

ML06 · Gradient-check diagnostic

Priority: P0 · Base timebox: 20 min

Prompt

Build a float64 central-difference checker for scalar loss and selected parameter coordinates.

Complete practice contract

The function must be deterministic, scalar-valued, and differentiable at the test point. Use float64 parameters and central differences. No dropout resampling or mutable optimizer state during evaluation.

Test agenda

Random coordinates; relative and absolute error; non-differentiable points avoided.

Follow-up challenge

Directional derivatives for large parameter vectors.

Worked solution, example and follow-up answer

Solution

For coordinate i, estimate g_i=[f(x+εe_i)-f(x-εe_i)]/(2ε). Central truncation error is O(ε²), while roundoff grows as ε shrinks, so neither a giant nor machine-minimum ε is appropriate. Start near 1e-6 for order-one float64 inputs and sweep several ε values when diagnosing disagreement.

Compare |g_num-g| ≤ atol+rtol·max(|g_num|,|g|). Relative error alone exaggerates disagreements near zero. Perturb copies so the original parameter array is unchanged even if evaluation raises an exception. Coordinate checking costs 2P forward evaluations; random coordinate sampling localizes errors cheaply.

Worked example

f(x)=sum(x²), x=[2,-3] gives analytic gradient [4,-6]. With ε=1e-6 the finite-difference values should agree to tight tolerance. At f(x)=max(x,0), x=0, a central difference is 0.5 although the implementation may define the subgradient as 0; that is not automatically a bug.

Follow-up answer

For large models choose a random direction v and compare g·v with [f(x+εv)-f(x-εv)]/(2ε). This tests a projection of the gradient with two forward passes; it does not identify the faulty coordinate and can miss specially aligned errors.

ML07 · K-means

Priority: P0 · Base timebox: 45 min

Prompt

Implement Lloyd iterations for X [N,D]; return centers, labels and inertia with a stated empty-cluster policy.

Complete practice contract

Finite X[N,D], initial centers[K,D], N,K,D>0; max_iter≥0, tol≥0. Assignment ties choose the smallest center index. Empty clusters retain their old center. Return centers, final nearest labels, and sum of squared distances.

Test agenda

Repeated points; K=1; empty cluster; convergence; labels match returned centers.

Follow-up challenge

Blocked assignment; seeding; K>N policy; deterministic tie handling.

Worked solution, example and follow-up answer

Solution

Alternate exact nearest-center assignment with per-cluster means. For fixed centers, assigning each point to its nearest center minimizes the objective over labels; for fixed labels, the mean minimizes squared error over that center. Thus complete ordinary Lloyd steps do not increase the objective under this empty-cluster policy, up to floating-point error. This does not prove global optimality.

Use counts=bincount(labels,minlength=K) and np.add.at(sums,labels,X). The latter matters because repeated advanced-index updates are buffered and can lose increments O08. Only divide nonempty clusters. After the final center update, reassign labels even if stopping because the budget expired. Time O(iterations·NKD); the reference blocks assignments and stores O(block·K) distance workspace.

Worked example

X=[0,1,9,10], initial centers=[0,10,100] yields centers=[0.5,9.5,100], labels=[0,0,1,1], inertia=1. The empty third cluster remains 100. This is a chosen API behavior, not a universal K-means requirement.

Follow-up answer

K>N is rejected by the provided k-means++ initializer, but the basic explicit-center solver can retain empty centers. A reseed-to-farthest policy is reasonable if specified; test its objective behavior separately. For a strict no-feature-loop implementation, use norm-expanded GEMM after discussing cancellation and memory.

ML08 · K-means++ variant

Priority: P1 · Base timebox: 30 min

Prompt

Implement squared-distance weighted initialization with an injected NumPy RNG.

Complete practice contract

Choose K center indices without replacement using an injected RNG, 1≤K≤N. Repeated point values may still produce equal centers. If all remaining squared-distance mass is zero, sample uniformly among unchosen indices.

Test agenda

All points identical; zero sampling mass; uniqueness policy; seeded replay.

Follow-up challenge

Explain why improved seeding helps but does not guarantee the global optimum.

Worked solution, example and follow-up answer

Solution

Choose the first index uniformly. Maintain d_i², distance to the nearest selected center. At each step sample index i with probability d_i²/sum_j d_j²; add it, then update d_i²←min(d_i²,||x_i-c_new||²). Only one new distance column is needed per selected center. Complexity O(NKD), memory O(N+KD).

Do not use ordinary distance rather than squared distance by accident. Injecting the RNG rather than resetting a global seed makes experiments reproducible and composable. Setting chosen indices to zero mass prevents duplicate indices when the total mass is positive. The zero-mass fallback is necessary when there are fewer distinct positions than requested centers.

Worked example

Points [0,0,10] and first center index 0 produce masses [0,0,100], so the second center is at 10. With all points equal, every mass is zero; the initializer still returns K valid, distinct indices under the fallback.

Follow-up answer

Better initialization reduces some poor local minima and often saves iterations, but it is not a global-optimum guarantee. Multiple seeded restarts and choosing the lowest converged objective are a separate technique. This specific initializer is the authored practice choice.

ML09 · Memory-bounded pairwise distance

Priority: P1 · Base timebox: 30 min

Prompt

Compute nearest centroid assignments without allocating [N,K,D]; allow blocks over N.

Complete practice contract

Compute nearest labels and squared distances without a full N×K×D tensor. Inputs may have large shared coordinate offsets. Explicitly state the memory budget and numerical tradeoff.

Test agenda

Compare direct subtraction reference; negative roundoff distances; large offsets.

Follow-up challenge

Peak-memory budget; cancellation tradeoffs; top-k nearest centers.

Worked solution, example and follow-up answer

Solution

The familiar identity D²=||X||²[:,None]+||C||²[None,:]-2XCᵀ uses O(NK) rather than O(NKD) memory and leverages GEMM. Clamp small negative roundoff to zero, but understand that clamping cannot repair incorrect neighbor rankings caused by cancellation between large nearly equal terms. Translating both point sets by a common origin reduces some cancellation.

The included robust reference instead blocks N and accumulates squared coordinate differences into a block×K matrix one feature at a time. That introduces a D-loop, not a per-point loop, and avoids the norm-expansion cancellation. Both methods have O(NKD) arithmetic, but their throughput differs substantially. Compare against direct subtraction on small data before optimizing.

Worked example

For N=100000,K=128,D=64, a float64 N×K×D difference tensor is about 6.55 GB. A 1024×128 distance workspace is about 1.05 MB, excluding inputs and temporaries. These are decimal bytes for the stated shapes, not measured peak RSS.

Follow-up answer

For top-k neighbors, maintain k candidates per point and merge block candidates using partial selection, then sort only the selected set. Tie ordering must be explicit. Peak memory includes temporary deltas, matrix products, and outputs, not merely the variable named distances.

ML10 · Multi-head self-attention

Priority: P0 · Base timebox: 45 min

Prompt

PyTorch: x [B,T,D], H heads. Implement projections, head transforms, attention and output projection without nn.MultiheadAttention or SDPA.

Complete practice contract

x[B,T,D], H heads with D divisible by H. Separate learned Q/K/V and output projections may be fused into one QKV projection. Boolean mask True means allowed; shape must broadcast to [B,H,Tq,Tk]. Fully masked rows produce zero attention output.

Test agenda

D divisible by H; non-contiguous tensors; output shape; reference parity with shared weights.

Follow-up challenge

Padding and causal masks; all-masked rows; explicit mask meaning.

Worked solution, example and follow-up answer

Solution

Project to Q,K,V, reshape to [B,T,H,d], transpose to [B,H,T,d], and compute S=QKᵀ/√d. Softmax runs over the key axis, not query or head axes. Multiply P@V, transpose back, reshape to [B,T,D], then output-project. Use reshape after transposes unless contiguity has been established.

Set disallowed scores to -infinity, but replace an entirely masked score row with zeros before softmax and zero its probabilities afterward. This prevents NaNs in both forward and backward. A post-hoc nan_to_num may hide a broken derivative. The reference has no output bias so a fully masked attention branch stays zero. Standard dense score storage is O(BHT²); arithmetic is O(BT²D), plus projections.

Worked example

B=2,T=5,D=8,H=2 gives heads[2,2,5,4], scores[2,2,5,5], output[2,5,8]. Causal allow[i,j]=(j≤i). Padding keys use valid_key[:,None,None,:]; combine with causal by boolean AND.

Follow-up answer

Padded queries are distinct from padded keys: optionally zero those output rows or exclude them from loss. PyTorch SDPA also treats True as allowed O03; some other attention APIs invert that meaning. Compare using identical projected tensors, dropout=0, and appropriate floating-point tolerance.

ML11 · Runnable Transformer encoder

Priority: P0 · Base timebox: 45 min

Prompt

Compose attention, residuals, normalization and FFN into a runnable encoder with a scalar loss and backward pass.

Complete practice contract

Implement one pre-normalized encoder block: residual attention followed by residual FFN. Inputs [B,T,D]; hidden width F; GELU; no dropout in the reference. Position information must be supplied outside this block when needed.

Test agenda

Every trainable parameter receives finite gradients; batch permutation equivariance; no accidental cross-batch attention.

Follow-up challenge

Pre-norm versus post-norm; dropout train/eval; parameter count.

Worked solution, example and follow-up answer

Solution

The block is u=x+MHA(LayerNorm(x)); y=u+Linear2(GELU(Linear1(LayerNorm(u)))). LayerNorm reduces only the last feature axis, so examples and timesteps are not mixed by normalization. Attention mixes sequence positions only within each batch element. A runnable test computes a scalar loss from y and calls backward; every intended parameter should receive a finite gradient.

For bias-free attention and biased FFN, parameters total 4D²+2DF+F+5D: QKV and output weights give 4D², FFN weights 2DF, FFN biases F+D, two affine LayerNorms 4D. This count is for the stated block, not all Transformer variants. Test batch permutation equivariance and noncontiguous input, not just shape.

Worked example

D=8,F=16 gives 4·64+2·8·16+16+5·8=568 parameters. With H=2 and T=5, y has the same [B,5,8] shape. A residual branch can remain nonzero at a masked query because x itself is still present.

Follow-up answer

Post-norm instead normalizes after residual addition; it changes gradient paths and training behavior, not merely syntax. Training dropout should be disabled for deterministic reference comparisons. The report confirms a runnable encoder, but pre-norm, GELU, masks and exact widths here are authored choices.

ML12 · LayerNorm and RMSNorm

Priority: P1 · Base timebox: 25 min

Prompt

Implement forward over the feature axis, with epsilon inside the square root and configurable affine terms.

Complete practice contract

Normalize over the final feature axis with population moments; eps is inside sqrt. Optional per-feature gain and bias. Preserve a defined accumulation dtype for low-precision input.

Test agenda

Constant input; small magnitude; mixed precision; compare supported reference APIs.

Follow-up challenge

Derive LayerNorm backward; explain what RMSNorm does not center.

Worked solution, example and follow-up answer

Solution

LayerNorm: μ=mean(x), c=x-μ, r=(mean(c²)+ε)^(-1/2), y=γ·c·r+β. RMSNorm: r=(mean(x²)+ε)^(-1/2), y=γ·x·r; it does not subtract μ. For LayerNorm backward set g=dy·γ and xhat=c·r, then dx=r·[g-mean(g)-xhat·mean(g·xhat)]. Sum dy and dy·xhat over non-feature dimensions for affine gradients.

For RMSNorm backward, dx=r·g-x·r³·mean(g·x). These formulas retain eps through r; do not casually use sample variance with divisor D-1. For fp16/bfloat16, form moments in float32; float64 reference comparisons should stay float64.

Worked example

x=[5,5,5] has LayerNorm output zero before bias; RMSNorm output is approximately [1,1,1], not zero. For x=[0,0], both are finite only because eps is positive.

Follow-up answer

BatchNorm uses statistics across batch and spatial positions for each channel and normally has train/eval running-statistics behavior; LayerNorm and RMSNorm do not need running moments. A norm is not automatically interchangeable with another just because output shape matches.

GE11 · Farthest-point sampling

Prompt

Follow-up challenge

Explain sequential dependency; maintain minimum distances incrementally.

Worked solution, example and follow-up answer

Solution

Points at [0,1,3,3], K=4 and first index 0 yield indices [0,2,1,3]. The two points at 3 have different indices; the final duplicate-coordinate point must still be selected only once.

Follow-up answer

Approximate or batched FPS changes selection semantics. Random sampling is much cheaper but has different coverage behavior. When K is large, discuss whether exact greedy coverage is necessary for the model rather than treating FPS as a mandatory preprocessing step.

EV01 · Detection precision-recall / AP

Prompt

Worked solution, example and follow-up answer

Solution

SE09 · Tiled CUDA GEMM

Priority: P2 · Base timebox: 60 min

Prompt

Implement a shared-memory tiled matrix product with arbitrary M,N,K and a correctness-first launch contract.

Complete practice contract

Compute C[M,N]=A[M,K] @ B[K,N] in row-major float32 with tile size T and arbitrary dimensions. One T×T thread block computes one output tile. The worked design handles partial tiles with zero-filled loads and masked final stores. It is not a claim of production GEMM performance.

Test agenda

Partial tiles; rectangular matrices; each thread reaches required barriers.

Follow-up challenge

Arithmetic intensity; coalescing; bank conflicts; tensor-core path; benchmark honestly.

Worked solution, example and follow-up answer

Solution

Let row=blockIdx.yT+threadIdx.y and col=blockIdx.xT+threadIdx.x. For tile index q, cooperatively load As[ty,tx]=A[row,qT+tx] when in bounds, else 0; load Bs[ty,tx]=B[qT+ty,col] when in bounds, else 0. Synchronize the entire block. Each thread accumulates sum_j As[ty,j]*Bs[j,tx] for j in [0,T). Synchronize again before any thread overwrites the shared tiles for the next q. After all ceil(K/T) tiles, store only if row<M and col<N.

The first barrier protects reads after loads; the second protects unfinished reads before the next overwrite. Threads outside output bounds still participate in loads and barriers. Compared with independent dot products, tiling reuses loaded values across multiple output elements; arithmetic intensity grows with tile size until register/shared-memory/occupancy constraints intervene.

Worked example

With M=17,N=19,K=5,T=16, the grid has 2×2 blocks and one K tile. Most loads in that K tile are zero-padded. The bottom/right blocks must still execute all barriers even though many threads have no output cell.

class RLEIndex:
    """Grammar: one ASCII letter then a positive decimal count; repeated runs allowed.

    Preprocessing O(encoded length), memory O(runs), query O(log runs).
    Python integers prevent decoded-length overflow; negative indexing is rejected.
    """
    def __init__(self, encoded: str):
        self.characters: list[str] = []; self.ends: list[int] = []
        pos=0; total=0
        for match in re.finditer(r'([A-Za-z])([0-9]+)',encoded):
            if match.start()!=pos or int(match.group(2))<=0:
                raise ValueError('invalid RLE grammar/count')
            total += int(match.group(2)); self.characters.append(match.group(1)); self.ends.append(total)
            pos=match.end()
        if pos!=len(encoded):
            raise ValueError('invalid RLE grammar')
        self.length=total

    def __getitem__(self,index: int) -> str:
        if not isinstance(index,int) or not 0<=index<self.length:
            raise IndexError('decoded index outside range')
        return self.characters[bisect_right(self.ends,index)]


def parse_csv(text: str) -> list[list[str]]:
    """A specified dialect, not every vendor's CSV dialect.

    Comma separator; LF, CRLF or CR record terminators; double-quoted fields with
    doubled-quote escape and embedded newlines. Quoting must start at field start;
    after its closing quote only a delimiter or record terminator may follow.
    Empty input -> []; trailing record terminator adds no extra row.
    Malformed quoting raises ValueError: do not guess a recovery boundary.
    """
    rows=[]; row=[]; field=[]; state='start'; active=False; index=0
    while index<len(text):
        char=text[index]
        if state=='quoted':
            if char=='"':
                state='after_quote'
            else:
                field.append(char)
            active=True; index+=1; continue
        if state=='after_quote' and char=='"':
            field.append('"'); state='quoted'; index+=1; continue
        if char==',':
            row.append(''.join(field)); field=[]; state='start'; active=True; index+=1; continue
        if char in '\r\n':
            row.append(''.join(field)); rows.append(row); row=[]; field=[]; state='start'; active=False
            index += 2 if char=='\r' and index+1<len(text) and text[index+1]=='\n' else 1
            continue
        if state=='after_quote':
            raise ValueError(f'unexpected character after closing quote at offset {index}')
        if char=='"':
            if state!='start':
                raise ValueError(f'quote inside unquoted field at offset {index}')
            state='quoted'; active=True; index+=1; continue
        field.append(char); state='unquoted'; active=True; index+=1
    if state=='quoted':
        raise ValueError('unterminated quoted field')
    if active or row or field:
        row.append(''.join(field)); rows.append(row)
    return rows


def validate_rows(rows: list[list[str]], schema: dict[str,Callable[[str],object]]) -> list[dict]:
    """Header must equal schema keys in order. Preserve raw rows plus typed data/errors.

    Record numbers are logical CSV record numbers (header=1), not physical lines.
    Width/type errors quarantine only that record; malformed quote syntax is handled
    by parse_csv before record validation. No inference of types from a header alone.
    """
    if not rows:
        return []
    header=rows[0]
    if len(set(header))!=len(header) or header!=list(schema) or any(not h for h in header):
        raise ValueError('unique nonempty header must match ordered schema')
    records=[]
    for number,raw in enumerate(rows[1:],start=2):
        errors=[]; data={name:None for name in header}
        if len(raw)!=len(header):
            errors.append(f'width: expected {len(header)}, received {len(raw)}')
        for index,name in enumerate(header):
            if index>=len(raw):
                continue
            try:
                data[name]=schema[name](raw[index])
            except (ValueError,TypeError,OverflowError) as exc:
                errors.append(f'{name}: {type(exc).__name__}')
        records.append(dict(record=number,raw=list(raw),data=data,is_valid=not errors,errors=errors))
    return records


def merge_intervals(intervals) -> list[tuple[float,float]]:
    """Union of finite half-open intervals; merge touching intervals, discard empties."""
    clean=[]
    for start,end in intervals:
        if not np.isfinite(start) or not np.isfinite(end) or end<start:
            raise ValueError('ordered finite endpoints required')
        if start<end:
            clean.append((start,end))
    clean.sort(); out=[]
    for start,end in clean:
        if not out or start>out[-1][1]:
            out.append((start,end))
        else:
            out[-1]=(out[-1][0],max(out[-1][1],end))
    return out


def coverage_gaps(intervals, window: tuple[float,float]) -> list[tuple[float,float]]:
    lo,hi=window
    if not np.isfinite(lo) or not np.isfinite(hi) or hi<lo:
        raise ValueError('invalid observation window')
    clipped=[(max(a,lo),min(b,hi)) for a,b in merge_intervals(intervals) if b>lo and a<hi]
    out=[]; cursor=lo
    for a,b in clipped:
        if cursor<a: out.append((cursor,a))
        cursor=max(cursor,b)
    if cursor<hi: out.append((cursor,hi))
    return out


def peak_concurrency(intervals) -> int:
    """Half-open events: end (-1) before start (+1) at equal timestamps."""
    events=[]
    for a,b in intervals:
        if not np.isfinite(a) or not np.isfinite(b) or b<a:
            raise ValueError('ordered finite endpoints required')
        if a<b: events.extend(((a,1),(b,-1)))
    active=best=0
    for _,delta in sorted(events):
        active+=delta; best=max(best,active)
    return best


def toposort(nodes: int, edges) -> list[int]:
    """Nodes 0..nodes-1, edges prerequisite->dependent; duplicate edges ignored.

    Min-heap gives deterministic smallest-available order. O((V+E) log V).
    Cycles raise ValueError (this compact reference does not recover a cycle path).
    """
    if nodes<0: raise ValueError('nonnegative node count required')
    adjacency=[set() for _ in range(nodes)]; degree=[0]*nodes
    for a,b in edges:
        if not 0<=a<nodes or not 0<=b<nodes: raise ValueError('unknown node')
        if b not in adjacency[a]: adjacency[a].add(b); degree[b]+=1
    ready=[i for i,d in enumerate(degree) if d==0]; heapq.heapify(ready); order=[]
    while ready:
        node=heapq.heappop(ready); order.append(node)
        for nxt in adjacency[node]:
            degree[nxt]-=1
            if degree[nxt]==0: heapq.heappush(ready,nxt)
    if len(order)!=nodes: raise ValueError('dependency cycle')
    return order


def match_timestamps(query, reference, tolerance: float) -> np.ndarray:
    """Independent nearest match with reference reuse, earlier index wins ties.

    Reference timestamps are strictly increasing. This is offline nearest matching,
    not a causal online policy or a one-to-one assignment algorithm.
    """
    q=_finite(query,1); r=_finite(reference,1)
    if tolerance<0 or not np.isfinite(tolerance) or np.any(np.diff(r)<=0):
        raise ValueError('finite nonnegative tolerance, strictly increasing reference required')
    result=np.full(len(q),-1,np.int64)
    if len(r)==0: return result
    right=np.searchsorted(r,q); left=np.maximum(right-1,0); right=np.minimum(right,len(r)-1)
    choose=np.where(np.abs(q-r[left])<=np.abs(q-r[right]),left,right)
    valid=np.abs(q-r[choose])<=tolerance; result[valid]=choose[valid]
    return result

def calibration(probabilities: np.ndarray, targets: np.ndarray,
                bins: int = 10) -> dict:
    """Top-label ECE; multiclass SUM-over-classes Brier; mean NLL.

    Equal-width bins [b/B,(b+1)/B), with 1 included in the last bin. argmax ties
    choose the lowest class. Zero probability of a true class gives infinite NLL.
    """
    p=_finite(probabilities,2); y=np.asarray(targets)
    if len(p)==0 or p.shape[1]<2 or y.shape!=(len(p),) or y.dtype.kind not in 'iu' or bins<1:
        raise ValueError('nonempty [N,C], integer labels [N], bins>=1 required')
    if np.any(p<0) or np.any(p>1) or not np.allclose(p.sum(1),1.,rtol=1e-8,atol=1e-10) or np.any(y<0) or np.any(y>=p.shape[1]):
        raise ValueError('invalid probabilities/labels')
    confidence=p.max(1); correct=p.argmax(1)==y
    index=np.minimum((confidence*bins).astype(int),bins-1)
    count=np.bincount(index,minlength=bins)
    confidence_sum=np.bincount(index,weights=confidence,minlength=bins)
    correct_sum=np.bincount(index,weights=correct,minlength=bins)
    acc=np.divide(correct_sum,count,out=np.zeros(bins),where=count>0)
    conf=np.divide(confidence_sum,count,out=np.zeros(bins),where=count>0)
    ece=float((count*np.abs(acc-conf)).sum()/len(p))
    residual=p.copy(); residual[np.arange(len(p)),y]-=1
    py=p[np.arange(len(p)),y]
    nll=float(-np.log(py).mean()) if np.all(py>0) else float('inf')
    return dict(ece=ece,brier=float((residual**2).sum(1).mean()),nll=nll,
                counts=count,accuracy=acc,confidence=conf)

    Each trip has equal weight, not each frame. Percentile interval, not a proof
    of safety and not a remedy for dependence between trips.

def detection_ap(boxes: np.ndarray, scores: np.ndarray, gt: np.ndarray,
                 threshold: float = .5) -> dict:
    """ONE IMAGE, ONE CLASS, continuous xyxy. All-points interpolated AP.

    Greedy score order; equal scores use input index. Each detection takes the
    highest-IoU unmatched GT at/above threshold. This is an authored definition,
    not a drop-in replacement for detection or autonomy evaluators with ignore/difficulty rules.
    No GT -> AP NaN. GT but no predictions -> AP 0.
    """
    boxes=_boxes(boxes); gt=_boxes(gt); s=_finite(scores,1)
    if len(s)!=len(boxes) or not 0<=threshold<=1:
        raise ValueError('invalid AP inputs')
    order=np.lexsort((np.arange(len(s)),-s)); overlap=pairwise_iou(boxes[order],gt)
    used=np.zeros(len(gt),bool); tp=np.zeros(len(s),bool)
    for i in range(len(s)):
        available=np.where(used,-1.,overlap[i])
        if len(gt):
            j=int(available.argmax())
            if available[j]>=threshold:
                tp[i]=True; used[j]=True
    cumulative=tp.cumsum(); precision=cumulative/np.arange(1,len(tp)+1)
    recall=cumulative/len(gt) if len(gt) else np.zeros(len(tp))
    if not len(gt):
        ap=float('nan')
    else:
        # Precision envelope, with sentinels, integrated only where recall advances.
        r=np.r_[0.,recall,1.]; p=np.r_[0.,precision,0.]
        p=np.maximum.accumulate(p[::-1])[::-1]
        ap=float(np.sum((r[1:]-r[:-1])*p[1:]))
    return dict(ap=ap,precision=precision,recall=recall,tp=tp,order=order)


def fault_posterior(prior: float, positive_given_fault: float,
                    positive_given_good: float) -> float:
    """P(fault | positive diagnostic); all three inputs are known probabilities."""
    if any(not np.isfinite(x) or not 0<=x<=1 for x in (prior,positive_given_fault,positive_given_good)):
        raise ValueError('probabilities must be in [0,1]')
    numerator=prior*positive_given_fault
    denominator=numerator+(1-prior)*positive_given_good
    if denominator==0:
        raise ValueError('conditioning event has zero probability')
    return numerator/denominator

"""Geometry with explicit continuous-coordinate and frame conventions.

Transforms T_a_from_b satisfy column-vector p_a = R @ p_b + t.
Points are stored as rows, so the array operation is P_b @ R.T + t.
"""
from __future__ import annotations
import numpy as np
from .numerics import _finite


def _boxes(boxes: np.ndarray) -> np.ndarray:
    b = _finite(boxes, 2)
    if b.shape[1] != 4 or np.any(b[:, 2:] < b[:, :2]):
        raise ValueError('expected ordered continuous xyxy boxes [N,4]')
    return b


def pairwise_iou(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Zero union -> 0; zero-area boxes permitted; negative extents rejected."""
    a = _boxes(a); b = _boxes(b)
    left = np.maximum(a[:, None, :2], b[None, :, :2])
    right = np.minimum(a[:, None, 2:], b[None, :, 2:])
    inter = np.maximum(right-left, 0.).prod(axis=-1)
    union = ((a[:,2:]-a[:,:2]).prod(1)[:,None]
             + (b[:,2:]-b[:,:2]).prod(1)[None,:] - inter)
    return np.divide(inter, union, out=np.zeros_like(inter), where=union>0)


def nms(boxes: np.ndarray, scores: np.ndarray, classes: np.ndarray,
        threshold: float = .5) -> np.ndarray:
    """Class-aware greedy NMS. Equal scores choose lower input index. Suppress > threshold."""
    b = _boxes(boxes); s = _finite(scores, 1); c = np.asarray(classes)
    if s.shape != (len(b),) or c.shape != s.shape or not 0 <= threshold <= 1:
        raise ValueError('invalid NMS inputs')
    order = np.lexsort((np.arange(len(b)), -s)); keep = []
    while len(order):
        i = int(order[0]); keep.append(i); rest = order[1:]
        overlap = pairwise_iou(b[i:i+1], b[rest])[0]
        order = rest[~((c[rest] == c[i]) & (overlap > threshold))]
    return np.asarray(keep, dtype=np.int64)


def match_anchors(anchors: np.ndarray, gt: np.ndarray,
                  positive: float = .5, negative: float = .4) -> tuple[np.ndarray, np.ndarray]:
    """Labels -1 ignore / 0 negative / 1 positive. Forced collisions: later GT wins.

    This policy does NOT guarantee every GT retains a unique forced anchor.
    Assigned GT index is -1 for non-positive anchors.
    """
    anchors = _boxes(anchors); gt = _boxes(gt)
    if not 0 <= negative <= positive <= 1:
        raise ValueError('require 0<=negative<=positive<=1')
    labels = np.zeros(len(anchors), np.int64); assigned = np.full(len(anchors), -1, np.int64)
    if len(anchors) == 0 or len(gt) == 0:
        return labels, assigned
    iou = pairwise_iou(anchors, gt); best = iou.argmax(axis=1); values = iou.max(axis=1)
    labels[(values >= negative) & (values < positive)] = -1
    labels[values >= positive] = 1; assigned[labels == 1] = best[labels == 1]
    # An explicit GT loop makes collision semantics deterministic.
    for j, i in enumerate(iou.argmax(axis=0)):
        labels[i] = 1; assigned[i] = j
    return labels, assigned


def rotation_z(yaw: float) -> np.ndarray:
    if not np.isfinite(yaw):
        raise ValueError('finite yaw required')
    c,s = np.cos(yaw), np.sin(yaw)
    return np.array([[c,-s,0.],[s,c,0.],[0.,0.,1.]])


def sample_box(center: np.ndarray, size: np.ndarray, yaw: float, count: int,
               rng: np.random.Generator) -> np.ndarray:
    """Uniform volume sampling, not surface sampling, in a yaw-only 3D box."""
    center = _finite(center, 1); size = _finite(size, 1)
    if center.shape != (3,) or size.shape != (3,) or np.any(size <= 0) or count < 0:
        raise ValueError('center/positive size [3], count>=0 required')
    local = (rng.random((count, 3)) - .5) * size
    return local @ rotation_z(yaw).T + center


def points_in_boxes(points: np.ndarray, centers: np.ndarray, sizes: np.ndarray,
                    yaws: np.ndarray, atol: float = 1e-9) -> np.ndarray:
    """[N,3] x M yaw boxes -> [N,M] membership; inclusive faces with tolerance."""
    p = _finite(points,2); c = _finite(centers,2); s = _finite(sizes,2); y = _finite(yaws,1)
    if p.shape[1] != 3 or c.shape != s.shape or c.shape != (len(y),3) or np.any(s<=0) or atol<0:
        raise ValueError('incompatible boxes/points')
    delta = p[:,None,:] - c[None,:,:]
    co = np.cos(y); si = np.sin(y)
    local = np.stack((delta[...,0]*co+delta[...,1]*si,
                      -delta[...,0]*si+delta[...,1]*co, delta[...,2]),axis=-1)
    return (np.abs(local) <= s[None,:,:]/2 + atol).all(axis=-1)


def transform_history(points: np.ndarray, world_from_history: np.ndarray,
                      world_from_current: np.ndarray) -> np.ndarray:
    """[B,A,T,3], [B,T,4,4], [B,4,4] -> points in current ego frame.

    Assumes proper rigid homogeneous transforms. Does not perform motion compensation
    for within-scan acquisition times; callers must supply the correct time poses.
    """
    p = _finite(points,4); hist = _finite(world_from_history,4); cur = _finite(world_from_current,3)
    b,_,t,d = p.shape
    if d != 3 or hist.shape != (b,t,4,4) or cur.shape != (b,4,4):
        raise ValueError('incompatible trajectory/pose shapes')
    world = np.einsum('btij,batj->bati',hist[...,:3,:3],p) + hist[:,None,:,:3,3]
    delta = world - cur[:,None,None,:3,3]
    return np.einsum('bji,batj->bati',cur[:,:3,:3],delta)


def project_points(points: np.ndarray, camera_from_points: np.ndarray,
                   intrinsics: np.ndarray, image_hw: tuple[int,int],
                   near: float = 1e-9) -> tuple[np.ndarray, np.ndarray]:
    """Pinhole only, no distortion. Nonpositive/near-zero depth gives NaN UV."""
    p = _finite(points,2); t = _finite(camera_from_points,2); k = _finite(intrinsics,2)
    if p.shape[1] != 3 or t.shape != (4,4) or k.shape != (3,3) or near < 0:
        raise ValueError('invalid projection shapes')
    h,w = image_hw
    if h <= 0 or w <= 0:
        raise ValueError('positive image dimensions required')
    camera = p @ t[:3,:3].T + t[:3,3]
    hom = camera @ k.T; depth_ok = (camera[:,2] > near) & (np.abs(hom[:,2]) > near)
    uv = np.full((len(p),2),np.nan)
    uv[depth_ok] = hom[depth_ok,:2] / hom[depth_ok,2,None]
    valid = depth_ok & (uv[:,0]>=0) & (uv[:,0]<w) & (uv[:,1]>=0) & (uv[:,1]<h)
    return uv, valid


def bilinear(image: np.ndarray, xy: np.ndarray) -> np.ndarray:
    """HWC input; centers at integer coordinates; clamp coordinates to border."""
    image = _finite(image,3); p = _finite(xy,2); h,w,_ = image.shape
    if min(h,w) < 1 or p.shape[1] != 2:
        raise ValueError('nonempty HWC and [N,2] required')
    x = np.clip(p[:,0],0,w-1); y = np.clip(p[:,1],0,h-1)
    x0 = np.floor(x).astype(int); y0 = np.floor(y).astype(int)
    x1 = np.minimum(x0+1,w-1); y1 = np.minimum(y0+1,h-1)
    dx = (x-x0)[:,None]; dy = (y-y0)[:,None]
    return ((1-dy)*((1-dx)*image[y0,x0]+dx*image[y0,x1])
            + dy*((1-dx)*image[y1,x0]+dx*image[y1,x1]))

               hi: np.ndarray, voxel_size: np.ndarray) -> tuple[np.ndarray,np.ndarray,np.ndarray,np.ndarray]:

def fps(points: np.ndarray, k: int) -> np.ndarray:
    """Exact greedy FPS; first index 0; deterministic ties; never repeat an index."""
    p = _finite(points,2)
    if not 0 <= k <= len(p):
        raise ValueError('require 0<=k<=N')
    selected = np.empty(k,np.int64); minimum = np.full(len(p),np.inf)
    used = np.zeros(len(p),bool); index = 0
    for step in range(k):
        selected[step] = index; used[index] = True
        minimum = np.minimum(minimum,((p-p[index])**2).sum(axis=1))
        scores = np.where(used,-np.inf,minimum)
        index = int(scores.argmax())
    return selected


def rigid_align(source: np.ndarray, target: np.ndarray) -> tuple[np.ndarray,np.ndarray]:
    """Least-squares proper rigid transform. Reject rank<2 (rotation underdetermined)."""
    x = _finite(source,2); y = _finite(target,2)
    if x.shape != y.shape or x.shape[1] != 3 or len(x)<3:
        raise ValueError('paired [N,3], N>=3 required')
    xc = x-x.mean(0); yc = y-y.mean(0)
    h = xc.T @ yc
    if np.linalg.matrix_rank(h)<2:
        raise ValueError('degenerate correspondences')
    u,_,vt = np.linalg.svd(h)
    correction = np.eye(3); correction[-1,-1] = np.linalg.det(vt.T @ u.T)
    r = vt.T @ correction @ u.T
    return r, y.mean(0)-r@x.mean(0)


def ray_aabb(origin: np.ndarray, direction: np.ndarray, lo: np.ndarray,
             hi: np.ndarray) -> tuple[float,float] | None:

    o = _finite(origin,1); d = _finite(direction,1); lo = _finite(lo,1); hi = _finite(hi,1)
    if o.shape != (3,) or d.shape != (3,) or lo.shape != (3,) or hi.shape != (3,) or np.any(hi<lo) or not np.any(d):
        raise ValueError('invalid ray/box')
    enter,exit = 0.,np.inf
    for axis in range(3):
        if d[axis] == 0:
            if o[axis]<lo[axis] or o[axis]>hi[axis]:

            enter = max(enter,min(a,b)); exit = min(exit,max(a,b))
            if enter > exit:
                return None
    return float(enter),float(exit)

def quantize_xy(xy: np.ndarray, lo, hi, bins) -> tuple[np.ndarray,np.ndarray]:

def kalman_step(x: np.ndarray, p: np.ndarray, f: np.ndarray, q: np.ndarray,
                h: np.ndarray, r: np.ndarray, measurement: np.ndarray) -> tuple[np.ndarray,np.ndarray]:

    x = _finite(x,1); p = _finite(p,2); f = _finite(f,2); q = _finite(q,2)
    h = _finite(h,2); r = _finite(r,2); z = _finite(measurement,1)

    cov = residual@pp@residual.T+gain@r@gain.T
    return out,(cov+cov.T)/2

"""NumPy learning references. All losses use a documented mean reduction.

Original teaching implementations, with explicit contracts and test cases.
Float64 is intentional for these CPU numerical reference exercises.
"""
from __future__ import annotations
from collections.abc import Callable
import numpy as np


def _finite(x: np.ndarray, ndim: int | None = None) -> np.ndarray:
    x = np.asarray(x, dtype=np.float64)
    if (ndim is not None and x.ndim != ndim) or not np.isfinite(x).all():
        raise ValueError('wrong rank or non-finite input')
    return x


def softmax_ce(logits: np.ndarray, targets: np.ndarray,
               ignore_index: int = -100) -> tuple[float, np.ndarray]:
    """[N,C] logits, [N] int labels. Mean over valid rows; all ignored -> zeros."""
    z = _finite(logits, 2); y = np.asarray(targets)
    if z.shape[1] < 2 or y.shape != (z.shape[0],) or y.dtype.kind not in 'iu':
        raise ValueError('expected C>=2 and integer targets [N]')
    valid = y != ignore_index
    if np.any((y[valid] < 0) | (y[valid] >= z.shape[1])):
        raise ValueError('target outside class range')
    grad = np.zeros_like(z); count = int(valid.sum())
    if count == 0:
        return 0., grad
    a = z[valid]; a = a - a.max(axis=1, keepdims=True)
    exp_a = np.exp(a); mass = exp_a.sum(axis=1, keepdims=True)
    rows = np.arange(count); selected = y[valid]
    loss = np.mean(np.log(mass[:, 0]) - a[rows, selected])
    p = exp_a / mass
    p[rows, selected] -= 1.
    grad[valid] = p / count
    return float(loss), grad


def classifier_step(x: np.ndarray, targets: np.ndarray, w: np.ndarray,
                    b: np.ndarray, learning_rate: float) -> tuple[np.ndarray, np.ndarray, float]:
    """Return fresh parameters and pre-update loss. No input mutation."""
    x = _finite(x, 2); w = _finite(w, 2); b = _finite(b, 1)
    if x.shape[1] != w.shape[0] or b.shape != (w.shape[1],):
        raise ValueError('incompatible classifier shapes')
    if not np.isfinite(learning_rate) or learning_rate < 0:
        raise ValueError('learning_rate must be finite and nonnegative')
    loss, dz = softmax_ce(x @ w + b, targets)
    dw = x.T @ dz; db = dz.sum(axis=0)
    return w - learning_rate * dw, b - learning_rate * db, loss


def binary_logistic(logits: np.ndarray, targets: np.ndarray) -> tuple[float, np.ndarray]:
    """Binary BCE from logits; targets are 0 or 1; mean over all elements."""
    z = _finite(logits); y = _finite(targets)
    if z.size == 0 or y.shape != z.shape or not np.isin(y, [0., 1.]).all():
        raise ValueError('nonempty equal shapes with binary targets required')
    loss = np.mean(np.logaddexp(0., z) - y * z)
    # exp(-logaddexp(0,-z)) is sigmoid(z) without overflow.
    p = np.exp(-np.logaddexp(0., -z))
    return float(loss), (p - y) / z.size


def two_layer_loss(x: np.ndarray, targets: np.ndarray, w1: np.ndarray, b1: np.ndarray,
                   w2: np.ndarray, b2: np.ndarray) -> tuple[float, dict[str, np.ndarray]]:
    """Affine-ReLU-affine; derivative at the ReLU kink is defined as zero."""
    x = _finite(x, 2)
    hpre = x @ w1 + b1; h = np.maximum(hpre, 0.)
    loss, dz = softmax_ce(h @ w2 + b2, targets)
    dhpre = (dz @ w2.T) * (hpre > 0)
    return loss, dict(w1=x.T @ dhpre, b1=dhpre.sum(0),
                      w2=h.T @ dz, b2=dz.sum(0))


def finite_difference(f: Callable[[np.ndarray], float], x: np.ndarray,
                      eps: float = 1e-6) -> np.ndarray:
    """Central differences; f must be deterministic and return a scalar."""
    x = _finite(x).copy()
    if eps <= 0 or not np.isfinite(eps):
        raise ValueError('eps must be positive and finite')
    grad = np.empty_like(x)
    for index in np.ndindex(x.shape):
        plus = x.copy(); minus = x.copy()
        plus[index] += eps; minus[index] -= eps
        grad[index] = (f(plus) - f(minus)) / (2 * eps)
    return grad


def nearest_centroids(x: np.ndarray, centers: np.ndarray,
                      block_size: int = 1024) -> tuple[np.ndarray, np.ndarray]:
    """O(NKD) time, O(block_size*K) workspace; no [N,K,D] allocation.

    Accumulate one feature at a time to avoid the cancellation of norm-expanded
    distances. This feature loop is a correctness-first tradeoff versus GEMM.
    Each iteration still compares all points in a block with all centroids.
    """
    x = _finite(x, 2); c = _finite(centers, 2)
    if c.shape[0] == 0 or x.shape[1] != c.shape[1] or x.shape[1] == 0 or block_size < 1:
        raise ValueError('nonempty centroids/features, matching D, positive block required')
    labels = np.empty(len(x), dtype=np.int64); distances = np.empty(len(x))
    for start in range(0, len(x), block_size):
        end = min(start + block_size, len(x)); xb = x[start:end]
        d2 = np.zeros((len(xb), len(c)))
        for dim in range(x.shape[1]):
            delta = xb[:, dim, None] - c[None, :, dim]
            d2 += delta * delta
        if not np.isfinite(d2).all():
            raise ValueError('distance overflow: rescale input coordinates')
        idx = d2.argmin(axis=1)
        labels[start:end] = idx; distances[start:end] = d2[np.arange(len(xb)), idx]
    return labels, distances


def kmeans(x: np.ndarray, initial_centers: np.ndarray, max_iter: int = 100,
           tol: float = 1e-6) -> tuple[np.ndarray, np.ndarray, float]:
    """Lloyd iterations; keep the old center for an empty cluster.

    Stop when maximum center movement <= tol. Reassign after the last update,
    including when the iteration budget is exhausted. Ties choose lowest index.
    """
    x = _finite(x, 2); centers = _finite(initial_centers, 2).copy()
    if len(x) == 0 or max_iter < 0 or tol < 0 or not np.isfinite(tol):
        raise ValueError('nonempty X, nonnegative max_iter/tol required')
    nearest_centroids(x[:0], centers)  # validate dimensions even for max_iter=0
    for _ in range(max_iter):
        labels, _ = nearest_centroids(x, centers)
        counts = np.bincount(labels, minlength=len(centers))
        sums = np.zeros_like(centers)
        np.add.at(sums, labels, x)  # repeated labels must accumulate
        nxt = centers.copy(); nonempty = counts > 0
        nxt[nonempty] = sums[nonempty] / counts[nonempty, None]
        shift = np.linalg.norm(nxt - centers, axis=1).max()
        centers = nxt
        if shift <= tol:
            break
    labels, distances = nearest_centroids(x, centers)
    return centers, labels, float(distances.sum())


def kmeans_pp(x: np.ndarray, k: int, rng: np.random.Generator) -> np.ndarray:
    """Squared-distance weighted initialization; unique indices, not unique values."""
    x = _finite(x, 2)
    if not 1 <= k <= len(x):
        raise ValueError('require 1 <= k <= N')
    chosen = [int(rng.integers(len(x)))]; used = np.zeros(len(x), bool)
    used[chosen[0]] = True
    d2 = ((x - x[chosen[0]])**2).sum(axis=1)
    while len(chosen) < k:
        d2[used] = 0.; total = d2.sum()
        if not np.isfinite(total):
            raise ValueError('distance overflow: rescale inputs')
        if total == 0:
            index = int(rng.choice(np.flatnonzero(~used)))
        else:
            index = int(rng.choice(len(x), p=d2 / total))
        chosen.append(index); used[index] = True
        d2 = np.minimum(d2, ((x - x[index])**2).sum(axis=1))
    return x[chosen].copy()


def dropout(x: np.ndarray, p: float, rng: np.random.Generator,
            training: bool = True) -> tuple[np.ndarray, np.ndarray]:
    """Inverted dropout; second return is the cached backward multiplier."""
    x = _finite(x)
    if not 0 <= p < 1:
        raise ValueError('p must be in [0,1)')
    scale = ((rng.random(x.shape) >= p) / (1-p)) if training else np.ones_like(x)
    return x * scale, scale


def layer_norm(x: np.ndarray, eps: float = 1e-5) -> np.ndarray:
    """Feature-axis population variance; affine terms omitted."""
    x = _finite(x)
    if x.ndim < 1 or x.shape[-1] == 0 or eps <= 0:
        raise ValueError('nonempty feature axis and positive eps required')
    centered = x - x.mean(axis=-1, keepdims=True)
    return centered / np.sqrt((centered**2).mean(axis=-1, keepdims=True) + eps)


def rms_norm(x: np.ndarray, eps: float = 1e-5) -> np.ndarray:
    x = _finite(x)
    if x.ndim < 1 or x.shape[-1] == 0 or eps <= 0:
        raise ValueError('nonempty feature axis and positive eps required')
    return x / np.sqrt((x*x).mean(axis=-1, keepdims=True) + eps)


def online_attention(q: np.ndarray, k: np.ndarray, v: np.ndarray,
                     block_size: int = 64) -> np.ndarray:
    """Exact softmax attention for one query; a CPU reference, not FlashAttention."""
    q = _finite(q, 1); k = _finite(k, 2); v = _finite(v, 2)
    if len(k) == 0 or len(k) != len(v) or k.shape[1] != len(q) or len(q) == 0 or block_size < 1:
        raise ValueError('incompatible or empty attention inputs')
    maximum = -np.inf; mass = 0.; accum = np.zeros(v.shape[1])
    for start in range(0, len(k), block_size):
        scores = k[start:start+block_size] @ q / np.sqrt(len(q))
        new_max = max(maximum, float(scores.max()))
        correction = np.exp(maximum - new_max)
        weights = np.exp(scores - new_max)
        mass = mass * correction + weights.sum()
        accum = accum * correction + weights @ v[start:start+block_size]
        maximum = new_max
    return accum / mass


def patchify(x: np.ndarray, patch: tuple[int, int]) -> np.ndarray:
    """NCHW -> [B, (H/ph)*(W/pw), ph*pw*C]; pixel-major, channel-last patch order."""
    x = np.asarray(x)
    if x.ndim != 4:
        raise ValueError('expected NCHW')
    b,c,h,w = x.shape; ph,pw = patch
    if ph < 1 or pw < 1 or h % ph or w % pw:
        raise ValueError('patch must divide spatial dimensions')
    return x.reshape(b,c,h//ph,ph,w//pw,pw).transpose(0,2,4,3,5,1).reshape(b,-1,ph*pw*c)


def unpatchify(tokens: np.ndarray, channels: int, height: int, width: int,
               patch: tuple[int, int]) -> np.ndarray:
    p = np.asarray(tokens); ph,pw = patch
    if ph < 1 or pw < 1 or height % ph or width % pw or channels < 1:
        raise ValueError('invalid patch/image sizes')
    if p.ndim != 3 or p.shape[1:] != ((height//ph)*(width//pw),ph*pw*channels):
        raise ValueError('incompatible token shape')
    return p.reshape(len(p),height//ph,width//pw,ph,pw,channels).transpose(0,5,1,3,2,4).reshape(len(p),channels,height,width)

"""Readable PyTorch encoder primitives. CPU-testable; not optimized fused kernels.

Mask convention throughout: boolean True means attention is ALLOWED.
Low-precision input reductions are performed in float32; float64 stays float64.
"""
from __future__ import annotations
import math
import torch
from torch import nn


def attention(q: torch.Tensor, k: torch.Tensor, v: torch.Tensor,
              allow: torch.Tensor | None = None) -> torch.Tensor:
    """[...,Tq,D] x [...,Tk,D] x [...,Tk,Dv]. Fully masked rows output zeros.

    No attention dropout. All-masked rows are replaced BEFORE softmax to avoid
    NaNs in both forward and backward; simply nan_to_num after softmax is not enough.
    """
    if q.ndim<2 or k.ndim<2 or v.ndim<2 or q.shape[-1]!=k.shape[-1] or k.shape[-2]!=v.shape[-2] or k.shape[-2]==0 or q.shape[-1]==0:
        raise ValueError('invalid attention shapes')
    if q.dtype!=k.dtype or q.dtype!=v.dtype or q.device!=k.device or q.device!=v.device:
        raise ValueError('matching dtype/device required')
    dtype=torch.float32 if q.dtype in (torch.float16,torch.bfloat16) else q.dtype
    scores=q.to(dtype) @ k.to(dtype).transpose(-2,-1) / math.sqrt(q.shape[-1])
    if allow is None:
        probabilities=scores.softmax(dim=-1)
    else:
        if allow.dtype!=torch.bool or allow.device!=q.device:
            raise ValueError('allow must be bool on the input device')
        mask=torch.broadcast_to(allow,scores.shape)
        has_key=mask.any(dim=-1,keepdim=True)
        masked=scores.masked_fill(~mask,-torch.inf)
        safe=torch.where(has_key,masked,torch.zeros_like(masked))
        probabilities=safe.softmax(dim=-1)
        probabilities=torch.where(mask & has_key,probabilities,torch.zeros_like(probabilities))
    return (probabilities @ v.to(dtype)).to(q.dtype)


class MHA(nn.Module):
    def __init__(self,dimension: int,heads: int):
        super().__init__()
        if dimension<1 or heads<1 or dimension%heads:
            raise ValueError('dimension must be a positive multiple of heads')
        self.dimension=dimension; self.heads=heads; self.head_dim=dimension//heads
        self.qkv=nn.Linear(dimension,3*dimension,bias=False)
        # No output bias, so a fully masked query remains zero before residual addition.
        self.output=nn.Linear(dimension,dimension,bias=False)

    def forward(self,x: torch.Tensor,allow: torch.Tensor | None = None) -> torch.Tensor:
        if x.ndim!=3 or x.shape[-1]!=self.dimension:
            raise ValueError('expected [B,T,D]')
        b,t,_=x.shape
        qkv=self.qkv(x).reshape(b,t,3,self.heads,self.head_dim).permute(2,0,3,1,4)
        q,k,v=qkv.unbind(dim=0)
        result=attention(q,k,v,allow).transpose(1,2).reshape(b,t,self.dimension)
        return self.output(result)


class EncoderBlock(nn.Module):
    """Pre-LayerNorm encoder, GELU FFN, no dropout/position encoding in this block."""
    def __init__(self,dimension: int,heads: int,hidden: int):
        super().__init__()
        if hidden<1: raise ValueError('positive hidden size required')
        self.norm1=nn.LayerNorm(dimension); self.norm2=nn.LayerNorm(dimension)
        self.attn=MHA(dimension,heads)
        self.ffn=nn.Sequential(nn.Linear(dimension,hidden),nn.GELU(),nn.Linear(hidden,dimension))

    def forward(self,x: torch.Tensor,allow: torch.Tensor | None = None) -> torch.Tensor:
        x=x+self.attn(self.norm1(x),allow)
        return x+self.ffn(self.norm2(x))


class RMSNorm(nn.Module):
    def __init__(self,dimension: int,eps: float = 1e-5):
        super().__init__()
        if dimension<1 or eps<=0: raise ValueError('positive dimension/eps required')
        self.weight=nn.Parameter(torch.ones(dimension)); self.eps=eps

    def forward(self,x: torch.Tensor) -> torch.Tensor:
        if x.shape[-1]!=len(self.weight): raise ValueError('wrong feature dimension')
        work=x.float() if x.dtype in (torch.float16,torch.bfloat16) else x
        out=work*torch.rsqrt((work*work).mean(dim=-1,keepdim=True)+self.eps)
        return out.to(x.dtype)*self.weight

"""Small CPU vision references. Convolution means cross-correlation, as in PyTorch."""
from __future__ import annotations
from collections import deque
import numpy as np

from .numerics import _finite


def max_pool2d(x: np.ndarray, kernel: tuple[int,int] = (2,2),
               stride: tuple[int,int] = (2,2)) -> tuple[np.ndarray,np.ndarray]:
    """NCHW, valid windows, floor output size, row-major first tie.

    Returns values [B,C,OH,OW] and ORIGINAL input (row,col) indices [...,2].
    No padding in this API; negative values therefore need no sentinel handling.
    """
    x = _finite(x,4); kh,kw = kernel; sh,sw = stride
    if min(kh,kw,sh,sw)<1 or x.shape[2]<kh or x.shape[3]<kw:
        raise ValueError('positive kernel/stride and at least one valid window required')
    windows = sliding_window_view(x,(kh,kw),axis=(2,3))[:,:,::sh,::sw]
    b,c,oh,ow,_,_ = windows.shape
    flat = windows.reshape(b,c,oh,ow,kh*kw)
    local = flat.argmax(axis=-1)
    values = np.take_along_axis(flat,local[...,None],axis=-1)[...,0]
    row = np.arange(oh)[None,None,:,None]*sh + local//kw
    col = np.arange(ow)[None,None,None,:]*sw + local%kw
    return values, np.stack((row,col),axis=-1)


def max_pool2d_backward(dout: np.ndarray, indices: np.ndarray,
                        input_shape: tuple[int,int,int,int]) -> np.ndarray:
    """Overlapping windows may choose one input repeatedly: scatter-add, not assign."""
    dy = _finite(dout,4); indices = np.asarray(indices)
    if indices.shape != dy.shape+(2,) or indices.dtype.kind not in 'iu' or len(input_shape)!=4:
        raise ValueError('invalid gradient/index shapes')
    b,c,h,w = input_shape
    if dy.shape[:2] != (b,c) or np.any(indices[...,0]<0) or np.any(indices[...,0]>=h) or np.any(indices[...,1]<0) or np.any(indices[...,1]>=w):
        raise ValueError('indices outside original input')
    dx = np.zeros(input_shape)
    batch = np.broadcast_to(np.arange(b)[:,None,None,None],dy.shape)
    channel = np.broadcast_to(np.arange(c)[None,:,None,None],dy.shape)
    np.add.at(dx,(batch,channel,indices[...,0],indices[...,1]),dy)
    return dx


def conv2d(x: np.ndarray, weight: np.ndarray, stride: tuple[int,int] = (1,1),
           padding: tuple[int,int] = (0,0)) -> np.ndarray:
    """NCHW x [O,C,KH,KW], zero padding, no dilation/groups/bias."""
    x = _finite(x,4); w = _finite(weight,4); sh,sw = stride; ph,pw = padding
    if x.shape[1]!=w.shape[1] or min(sh,sw)<1 or min(ph,pw)<0:
        raise ValueError('invalid convolution parameters')
    xp = np.pad(x,((0,0),(0,0),(ph,ph),(pw,pw)))
    kh,kw = w.shape[-2:]
    if min(kh,kw)<1 or xp.shape[2]<kh or xp.shape[3]<kw:
        raise ValueError('kernel does not fit padded image')
    patches = sliding_window_view(xp,(kh,kw),axis=(2,3))[:,:,::sh,::sw]
    return np.einsum('bchwij,ocij->bohw',patches,w,optimize=True)


def components(image: np.ndarray, connectivity: int = 4) -> tuple[np.ndarray,int]:
    """Boolean foreground. Background label 0; components 1..count in scan order."""
    image = np.asarray(image,dtype=bool)
    if image.ndim!=2 or connectivity not in (4,8):
        raise ValueError('expected 2D image and 4/8 connectivity')
    labels = np.zeros(image.shape,np.int64); count = 0; h,w = image.shape
    offsets = [(-1,0),(1,0),(0,-1),(0,1)]
    if connectivity==8:
        offsets += [(-1,-1),(-1,1),(1,-1),(1,1)]
    for row in range(h):
        for col in range(w):
            if not image[row,col] or labels[row,col]:
                continue
            count += 1; labels[row,col] = count; queue = deque([(row,col)])
            while queue:
                y,x = queue.popleft()
                for dy,dx in offsets:
                    yy,xx = y+dy,x+dx
                    if 0<=yy<h and 0<=xx<w and image[yy,xx] and labels[yy,xx]==0:
                        labels[yy,xx] = count; queue.append((yy,xx))
    return labels,count


def fit_circle(points: np.ndarray) -> tuple[np.ndarray,float]:
    """Algebraic least squares after centering. Not robust to outliers by itself."""
    p = _finite(points,2)
    if p.shape[1]!=2 or len(p)<3:
        raise ValueError('need at least 3 2D points')
    origin = p.mean(0); q = p-origin
    a = np.column_stack((2*q,np.ones(len(q))))
    coeff,_,rank,_ = np.linalg.lstsq(a,(q*q).sum(1),rcond=None)
    if rank<3:
        raise ValueError('collinear or duplicate-only points')
    radius2 = coeff[2]+coeff[:2]@coeff[:2]
    if radius2<=0 or not np.isfinite(radius2):
        raise ValueError('nonpositive/invalid radius')
    return coeff[:2]+origin,float(np.sqrt(radius2))


def binary_focal(logits: np.ndarray, targets: np.ndarray,
                 gamma: float = 2., alpha: float = .25) -> float:
    """Mean binary focal loss. alpha weights positives; 1-alpha negatives."""
    z = _finite(logits); y = _finite(targets)
    if z.shape!=y.shape or z.size==0 or not np.isin(y,[0.,1.]).all() or gamma<0 or not 0<=alpha<=1:
        raise ValueError('invalid focal inputs')
    bce = np.logaddexp(0.,z)-y*z
    pt = np.exp(-bce)
    alpha_t = np.where(y==1,alpha,1-alpha)
    return float(np.mean(alpha_t*(1-pt)**gamma*bce))


def confusion(predicted: np.ndarray, target: np.ndarray, classes: int,
              ignore_index: int = -1) -> np.ndarray:
    """Rows=true, columns=predicted. Ignore targets before indexing."""
    p = np.asarray(predicted); y = np.asarray(target)
    if p.shape!=y.shape or p.dtype.kind not in 'iu' or y.dtype.kind not in 'iu' or classes<1:
        raise ValueError('integer equal-shaped labels required')
    valid = y!=ignore_index; p=p[valid].ravel(); y=y[valid].ravel()
    if np.any(p<0) or np.any(p>=classes) or np.any(y<0) or np.any(y>=classes):
        raise ValueError('label outside class range')
    return np.bincount(y*classes+p,minlength=classes*classes).reshape(classes,classes)

        throw std::invalid_argument("speed and bumps must be positive finite values");
    Lift lift_value;
    if (lift=="Cable") lift_value=Lift::Cable;
    else if (lift=="Chain") lift_value=Lift::Chain;
    else if (lift=="Launched") lift_value=Lift::Launched;
    else throw std::invalid_argument("unknown lift type");
    using Builder=std::function<std::unique_ptr<Coaster>()>;
    static const std::unordered_map<std::string,Builder> factory {
        {"Wooden", [] { return std::make_unique<Wooden>(); }},
        {"Steel", [] { return std::make_unique<Steel>(); }},
        {"Suspended", [] { return std::make_unique<Suspended>(); }}
    };
    const auto found=factory.find(type);
    if (found==factory.end()) throw std::invalid_argument("unknown coaster type");

class Matrix {
    std::size_t rows_,cols_;
    std::vector<double> data_;
    static std::size_t checked_size(std::size_t rows,std::size_t cols) {
        if (cols!=0 && rows>std::numeric_limits<std::size_t>::max()/cols)
            throw std::length_error("matrix dimensions overflow size_t");
        return rows*cols;
    }
public:
    Matrix(std::size_t rows,std::size_t cols)
        : rows_(rows),cols_(cols),data_(checked_size(rows,cols),0.0) {}
    // Default copy is deep through vector. Default move transfers storage.
    // As usual, only destruction/assignment is promised for a moved-from instance.
    std::size_t rows() const noexcept { return rows_; }
    std::size_t cols() const noexcept { return cols_; }
    double& at(std::size_t row,std::size_t col) {
        if (row>=rows_ || col>=cols_) throw std::out_of_range("matrix index");
        return data_.at(row*cols_+col);
    }

        if (row>=rows_ || col>=cols_) throw std::out_of_range("matrix index");
        return data_.at(row*cols_+col);
    }

        if (rows_!=other.rows_ || cols_!=other.cols_) throw std::invalid_argument("addition shape mismatch");
        Matrix out(rows_,cols_);

                    out.data_[i*other.cols_+j]+=a*other.data_[k*other.cols_+j];
            }
        return out;
    }
