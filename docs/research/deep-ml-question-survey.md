# Deep-ML question survey for torch_dojo

For additional questions from the current live catalog, see the [2026-10-06 follow-up](deep-ml-live-catalog-2026-10.md). This earlier survey records the narrower open-repository snapshot and its original dojo comparison.

Surveyed 2026-10-06. This **practice-source catalog** maps technical topics to dojo workouts. Deep-ML's [site](https://www.deep-ml.com/problems) serves problem details through JavaScript, so titles, difficulty labels, and topic summaries in the main table were checked against its [first-party open problem repository](https://github.com/Open-Deep-ML/DML-OpenProblem), whose build process feeds the site. Some newer items below are verified from a first-party [curated collection](https://www.deep-ml.com/collections/An%20Introduction%20to%20Statistical%20Learning) but lack repository metadata. Every listed `/problems/<id>` URL was also checked to resolve successfully. The repository's [Educational Use Only license](https://github.com/Open-Deep-ML/DML-OpenProblem/blob/main/LICENSE) warrants original dojo contracts, prose, examples, reference implementations, and verifiers if any topic is adapted. No problem statement, solution, or tests are copied here.

The overlap column compares the dojo at survey time (`0001`–`0081`) and the authored [`practice_bank/index.md`](../../practice_bank/index.md) bank. “Gap” means there was no dedicated runnable dojo exercise at survey time; a practice-bank mention does not count as a runnable implementation. RL topics selected from this survey are now [policy evaluation](../../dojo/0082_policy_evaluation.py), [Q-learning](../../dojo/0083_q_learning.py), and [REINFORCE](../../dojo/0084_reinforce_loss.py).

## Highest-value additions

1. **[18 — K-fold cross-validation](https://www.deep-ml.com/problems/18)**: useful entry into leakage-aware evaluation. Write an original split generator with seed, grouping, non-divisible fold sizes, and coverage invariants. This complements [`0073_paired_trip_bootstrap.py`](../../dojo/0073_paired_trip_bootstrap.py) rather than repeating it. [Source metadata](https://github.com/Open-Deep-ML/DML-OpenProblem/blob/main/questions/18_implement-k-fold-cross-validation/meta.json).
2. **[19 — PCA](https://www.deep-ml.com/problems/19)**: adds centering, scale decisions, eigenspaces, sign ambiguity, explained variance, and reconstruction checks; no present PCA dojo. [Source metadata](https://github.com/Open-Deep-ML/DML-OpenProblem/blob/main/questions/19_principal-component-analysis-pca-implementation/meta.json).
3. **[138 — Gini split](https://www.deep-ml.com/problems/138)**, then **[20 — decision tree](https://www.deep-ml.com/problems/20)**: a natural two-stage path from threshold search and weighted impurity to recursive fitting. Add ties, missing values, stopping limits, and out-of-sample prediction in original contracts. [138 source](https://github.com/Open-Deep-ML/DML-OpenProblem/blob/main/questions/138_find-the-best-gini-based-split-for-a-binary-decisi/meta.json); [20 source](https://github.com/Open-Deep-ML/DML-OpenProblem/blob/main/questions/20_decision-tree-learning/meta.json).
4. **[62 — RNN backpropagation through time](https://www.deep-ml.com/problems/62)**: a clear autograd bridge from the current scalar/linear backward exercises to a stateful sequence with temporal credit assignment. Stage it after an original simple recurrent forward pass. [Source metadata](https://github.com/Open-Deep-ML/DML-OpenProblem/blob/main/questions/62_implement-a-simple-rnn-with-backpropagation-throug/meta.json).
5. **[133 — Q-learning](https://www.deep-ml.com/problems/133)** and **[122 — REINFORCE](https://www.deep-ml.com/problems/122)**: cover tabular value learning and trajectory policy gradients. Current PPO/GRPO scripts handle objectives, not complete rollout-to-update estimators. [133 source](https://github.com/Open-Deep-ML/DML-OpenProblem/blob/main/questions/133_implement-q-learning-algorithm-for-mdps/meta.json); [122 source](https://github.com/Open-Deep-ML/DML-OpenProblem/blob/main/questions/122_policy-gradient-with-reinforce/meta.json).
6. **[160 — mixed precision training](https://www.deep-ml.com/problems/160)**: exercise master weights, scaling/unscaling, nonfinite gradients, and skipped steps. Deep-ML's public prompt uses a small float16 MSE class; a dojo version should progress to PyTorch behavior and realistic failure cases. [Source metadata](https://github.com/Open-Deep-ML/DML-OpenProblem/blob/main/questions/160_mixed_precision_training/meta.json).
7. **[276 — ROC curve](https://www.deep-ml.com/problems/276)** and **[277 — ROC AUC](https://www.deep-ml.com/problems/277)**: add ranked binary-classification evaluation, tied scores, empty classes, and threshold conventions. These are linked directly from Deep-ML's [statistical-learning collection](https://www.deep-ml.com/collections/An%20Introduction%20to%20Statistical%20Learning); difficulty and exact contracts were not available in the repository snapshot.

## Lower-priority overlaps and cautions

- For the dojo's **vision, 3D geometry, and autonomous-motion** focus, the inspected public source snapshot yielded little that beats existing `0042`–`0076`: its explicit computer-vision entries include elementary image brightness/contrast, while current dojo already covers projection, IoU, voxel pooling, box geometry, and trajectories. The additions above therefore mainly fill **general ML, evaluation, autograd/sequence, and RL** gaps. This is a limit of this survey, not a claim that the live Deep-ML catalog lacks other vision questions.
- [23 softmax](https://www.deep-ml.com/problems/23), [26 basic autograd](https://www.deep-ml.com/problems/26), [49 Adam](https://www.deep-ml.com/problems/49), [94 multi-head attention](https://www.deep-ml.com/problems/94), [101 GRPO](https://www.deep-ml.com/problems/101), [107 masked attention](https://www.deep-ml.com/problems/107), [131 sparse-window attention](https://www.deep-ml.com/problems/131), and [151 dropout](https://www.deep-ml.com/problems/151) strongly overlap existing dojo scripts. Use them as comparison material, not new problem slots.
- [130 CNN training with backpropagation](https://www.deep-ml.com/problems/130), [174 one-dimensional GAN](https://www.deep-ml.com/problems/174), and [187 ETL pipeline](https://www.deep-ml.com/problems/187) offer broader systems or training exercises, but are larger than the current bite-sized dojo form. [188 gradient checkpointing](https://www.deep-ml.com/problems/188) is labeled “easy” and its public description focuses on forward recomputation; an original exercise should require a meaningful backward/memory tradeoff before it earns a slot.
- Deep-ML's site advertises many more problems than this repository snapshot contains. This is a selective survey of first-party public source files, not a census of the live JavaScript catalog.
