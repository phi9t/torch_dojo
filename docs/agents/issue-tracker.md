# Issue tracker: Local Markdown

Issues and specs live under `.scratch/<feature-slug>/`.
The spec is `spec.md`; implementation tickets are separate numbered files
under `issues/NN-<slug>.md`. Record triage state with `Status:`, comments
under `## Comments`, and dependencies with `Blocked by: NN, NN`.
To publish or fetch a ticket, write or read its file. Resolve a ticket
by setting `Status: resolved` and recording its answer.
