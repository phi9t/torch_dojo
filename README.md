# Torch Dojo

PyTorch and NumPy coding workouts with a local staged evaluation runner.

Install the package in an environment with its declared dependencies, then run
`make test` for the runner checks or `make eval` for the reference verifiers.

## Origins

Torch Dojo builds on [TorchCode](https://github.com/duoan/TorchCode).
Credit to duoan and the upstream contributors for the original project.
