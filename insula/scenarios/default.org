#+TITLE: Torch Dojo GPU Jupyter scenario

In the TUI, =F10= advances one checkpoint or Python cell. =F9= browses completed
steps. The Emacs terminal uses =n= to advance, =p= to browse, =r= to restart,
and =q= to clean up and exit.

* Setup
Inspect the two-insula environment and authenticated server readiness.

* Connect
Start one =torch-dojo-gpu= kernel from the Emacs insula.
